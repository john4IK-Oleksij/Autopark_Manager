# Ітерація 11 — Картка водія

## Мета
Показати деталі водія й маршрути, на які його призначено.

## Обсяг
- Завантажувати водія за ID.
- Завантажувати список його маршрутів.
- Дозволяти призначення на маршрут і зняття з маршруту через перевірені API endpoint-и.
- Не показувати маршрути інших компаній як допустимі для призначення, якщо це обмеження відоме API.
- Показувати стани loading, empty, error і повідомлення про конфлікти.

## Критерії приймання
- Неіснуючий водій обробляється коректно.
- Успішні зміни відображаються після відповіді API.
- Дублікати та помилки бізнес-правил мають зрозумілі повідомлення.
- Сторінка адаптивна.
