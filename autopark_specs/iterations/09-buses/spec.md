# Ітерація 09 — Автобуси

## Мета
Реалізувати інтерфейс перегляду й керування автобусами згідно з API.

## Обсяг
- Список автобусів із номером, моделлю, кількістю місць і компанією.
- Створення/редагування/видалення лише за наявності відповідних endpoint-ів.
- Валідація обов'язкових полів та обробка дубліката номерного знака.
- Стани loading, empty, error та підтвердження видалення.

## Критерії приймання
- Список використовує реальні дані API.
- Помилки API показуються без втрати введених даних.
- Макет адаптивний від 360px.

## Після завершення
Оновити `progress.md` і зупинитися до підтвердження користувача.
