# Ітерація 04 — Пагінація та картка водія

## Мета
Підготувати API для сторінки списку водіїв і детальної картки водія.

## Обсяг
- Додати/узгодити `limit` та `offset` у GET списку водіїв.
- Обмежити допустимий `limit` і перевірити невід'ємний `offset`.
- Повернути стабільне сортування та узгоджений формат: `items`, `total`, `limit`, `offset`.
- Реалізувати або перевірити GET `/drivers/{id}`.
- Реалізувати або перевірити GET `/drivers/{id}/routes`.
- Список маршрутів водія має відповідати наявним призначенням.

## Критерії приймання
- Параметри пагінації валідовані.
- Кількість `total` відповідає загальній кількості водіїв, а не кількості на поточній сторінці.
- Сторінки не мають випадкового порядку.
- Для неіснуючого водія повертається `404`.
- Відповідь маршрутів узгоджена зі схемами API.

## Перевірка
Перевірити першу сторінку, наступну сторінку, порожню сторінку, некоректні параметри та неіснуючий ID.
