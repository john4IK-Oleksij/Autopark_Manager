# Ітерація 07 — Яскрава дизайн-система

## Мета
Визначити та реалізувати цілісний яскравий UI, не прив'язуючись до старої приглушеної палітри.

## Візуальний напрям
- Насичені зелені, рожеві, блакитні та додаткові яскраві акценти.
- Фон світлий і чистий; основний текст із високою читабельністю.
- Картки білі, радіус близько `20px`, легка тінь, щедрі відступи.
- Шрифт Manrope із запасним sans-serif.
- Яскраві кольори мають бути системними й послідовними, а не випадковими на кожному елементі.
- Забезпечити контраст для тексту, focus-станів, кнопок, помилок і disabled-елементів.

## Обсяг
- Створити CSS custom properties для фону, тексту, border, primary, accent, success, warning, danger і focus.
- Стилізувати кнопки, форми, картки, таблиці, бейджі, діалоги та повідомлення.
- Передбачити hover, focus-visible, active, disabled та error стани.
- Перевірити ширини від 360px.

## Обмеження
- Не копіювати попередні приглушені кольори як обов'язкові значення.
- Не використовувати колір як єдиний носій значення.
- Не жертвувати читабельністю заради яскравості.

## Критерії приймання
- Палітра централізована в CSS variables.
- Компоненти мають узгоджені стани.
- Інтерфейс адаптивний і доступний для клавіатурної навігації.
- Дизайн перевірено на вузькому екрані.
