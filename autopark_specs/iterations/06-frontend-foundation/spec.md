# Ітерація 06 — Frontend foundation

## Мета
Створити мінімальний каркас HTML/CSS/JavaScript і безпечний спільний спосіб виклику API.

## Обсяг
- Узгодити структуру frontend-файлів з наявним репозиторієм.
- Створити спільний API-клієнт для базового URL і обробки HTTP-помилок.
- Підготувати навігацію та базові layout-и.
- Реалізувати стани loading, empty та error.
- Підключити шрифт Manrope із системним fallback.

## Обмеження
- Не додавати frontend-фреймворк без потреби.
- Не дублювати fetch-логіку на кожній сторінці.
- Вставляти користувацькі значення в DOM безпечно через `textContent` або еквівалент.

## Критерії приймання
- Каркас відкривається без JavaScript-помилок.
- API-клієнт коректно обробляє JSON і помилки.
- Навігація працює на вузькому екрані.
- Якщо потрібен CORS, він налаштований на backend у погодженому обсязі.

Оновити `progress.md` і зупинитися до підтвердження користувача.
